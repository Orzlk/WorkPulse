## 数据与安全边界

- 本地数据库：Electron `userData/workpulse.db`；迁移备份：`userData/backups`。
- 导出为按 `public_id` 合并的逻辑 JSON 包；不导出设置、API Key 或本地仓库路径。
- 导入需先预览；确认 token 有效期、窗口归属与一次性消费约束；导入不探测本地路径或自动扫描 Git。
- Git 扫描只执行 `rev-parse` 和 `log`；不会执行写仓库命令。
- AI 仅接收已确认的范围快照，不接收未整理草稿、设置、API Key 或本地路径。
